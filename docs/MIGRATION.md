# 迁移与来源

本仓库的初始内容是从原 1213 工作树中选择的三个技能及其引用文件快照。选择时的来源提交基线为 `42fefb1`；`embedded-link-debug` 还包含迁移前已经存在的工作树修改。因此初始发布不能描述为该提交的逐字副本。

迁移只选取本仓库所需的工作树文件，以独立提交建立公开历史，不复制原仓库的完整历史、个人工具、凭据、账户快照或私人对话。私有来源仓库的访问权限不是使用本仓库的前提。

引用文件中的芯片、路径、协议、引脚、页面参数、构建与实物记录属于来源项目的历史证据。迁移和打包检查没有重新运行这些固件，没有烧录，也没有观测当前硬件；应用到其他工程前必须重新检查当前源码、配置、工具和接线。

三个技能的后续维护以本仓库为准，个人工具仍由原来的私有仓库维护。原工具可以显式调用这里的安装器，且应保留它的只读默认、完整预检和冲突拒绝规则。

仓库更新不自动覆盖已安装技能。先运行 `tools/Install-Skills.ps1 -Check`；若存在差异，应人工比较、保留有价值的本地修改，再根据用户授权决定安装位置和迁移方式。安装器本身不会修改全局规则或配置。

公开发布前仅将 GitHub 认证案例中的另一历史账号名称泛化为“其他账号”，保留排障方法。现有本机安装的三个技能文件未因仓库整理被重装或覆盖；因此公开源与旧安装可能存在这处已知差异，后续安装仍应正常比较而非强制覆盖。
